# AI Literature Review 2026

This repository contains an English critical literature survey of low-rank
parameter-efficient fine-tuning in models with at most 30 billion parameters.
The primary evidence set contains ten papers first published between February
and November 2026.

## Deliverables

- `report/main.tex`: LaTeX source for the report.
- `26723812-ChenxuanXin.pdf`: compiled PDF generated by GitHub Actions.
- `report/main.pdf`: compilation artifact inside the report directory.

## Topic

**The Effective-Capacity Turn: A Critical Survey of Low-Rank Adaptation in
Sub-30B Language Models (February-November 2026)**

The report compares update geometry, realized adapter capacity, layer and
module allocation, continual-learning alignment, input-conditioned adaptation,
and compact fixed-subspace adaptation. It explicitly separates evidence from
models below 30B parameters from larger-model or non-language experiments.

## Automatic build

Pushing to `main` runs `.github/workflows/build-report.yml`. The workflow:

1. compiles `report/main.tex` with a TeX Live container;
2. uploads the PDF as a workflow artifact;
3. commits the compiled PDF back to the repository.

## Local build

With TeX Live installed:

```bash
cd report
latexmk -pdf main.tex
```
